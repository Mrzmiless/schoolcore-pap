About the project

What is SchoolCore?

SchoolCore was created to help schools add more functionality without major changes to their infrastructure. Easy to install, use, and maintain by your own IT team.

Features

Everything you need, with no external dependencies

Self-hosted

Keep all school data on your own infrastructure with full control over it.

PWA Support

Students and teachers can access it via web or install it as an app on Android and iOS, with no App Store or Google Play required.

Easy to install

Built for school IT teams. Follow the step-by-step guide and get it up and running quickly.

Installation

Get started in a few steps

Follow this guide on your Ubuntu Server to get SchoolCore up and running.

01

Prepare the server

Connect via SSH, become root, and update the system.

sudo su
apt update && apt upgrade -y
reboot
02

Install dependencies

After reboot, install git, python3, nodejs, and npm.

sudo su
apt install -y git python3 nodejs npm
03

Clone the repository

Clone the repository and enter the project directory.

git clone https://github.com/Mrzmiless/schoolcore-pap.git
cd schoolcore-pap
04

Configure and run

Check the README on GitHub for the most up-to-date configuration and startup instructions.
