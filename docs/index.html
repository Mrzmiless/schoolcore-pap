About the project

What is SchoolCore?

SchoolCore was created to help schools add more functionality without major changes to their infrastructure. Easy to install, use, and maintain by your own IT team.

Features

Everything you need, with no external dependencies

Self-hosted

Keep all school data on your own infrastructure with full control over it. No need for cloud storage.

PWA Support

Students and teachers can access it via WebApp, install it as an app on Android and iOS, with no App Store or Google Play required.

Easy to install

Built for school IT teams. Follow the step-by-step guide and get it up and running quickly.

Server requirements

Minimum and recommended requirements

Currently only tested on Ubuntu Server.

Component Minimum Recommended
CPU x86_64, 4 cores x86_64, 6+ cores @ 3.0 GHz or higher
RAM 16 GB 32 GB+
Storage 10 GB 20 GB+ (SSD strongly recommended)
GPU Not required Only if using the media encoding module
Operating System Ubuntu Server (tested) Ubuntu Server (LTS)
