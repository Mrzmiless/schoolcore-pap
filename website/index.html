Sobre o projeto

O que é o SchoolCore?

O SchoolCore foi criado para ajudar escolas a ter mais funcionalidades sem grandes alterações na infraestrutura. Fácil de instalar, utilizar e manter pela tua própria equipa de TI.

Funcionalidades

Tudo o que precisas, sem dependências externas

Self-hosted

Mantém todos os dados da escola na tua própria infraestrutura, com controlo total sobre eles.

Suporte PWA

Alunos e docentes podem aceder pela web ou instalar como app no Android e iOS, sem App Store ou Google Play.

Fácil de instalar

Pensado para equipas de TI escolares. Segue o guia passo a passo e coloca-o a funcionar rapidamente.

Instalação

Começa em poucos passos

Segue este guia no teu servidor Ubuntu Server para colocar o SchoolCore a funcionar.

01

Preparar o servidor

Acede por SSH, entra em root e atualiza o sistema.

sudo su
apt update && apt upgrade -y
reboot
02

Instalar dependências

Após o reboot, instala git, python3, nodejs e npm.

sudo su
apt install -y git python3 nodejs npm
03

Clonar o repositório

Clona o repositório e entra na diretoria do projeto.

git clone https://github.com/Mrzmiless/schoolcore-pap.git
cd schoolcore-pap
04

Configurar e executar

Consulta o README no GitHub para as instruções mais atualizadas de configuração e arranque.
